# CypherAir X

CypherAir X is an offline OpenPGP encryption app for iPhone, iPad, Mac and Apple Vision Pro.

Version 2.0 is being rebuilt in this repository. For now the app only shows its name and version. The 1.x app is at the tag [`cypherair-v1.7.1-build17100`](https://github.com/cypherair/cypherair/tree/cypherair-v1.7.1-build17100).
